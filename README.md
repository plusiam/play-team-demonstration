# 팀 데몬스트레이션 진행 도구

> 사회자(교사)가 조건문을 던지고, 답과 점수를 부르고, 손 든 모둠에 점수를 얹는
> 한 판의 흐름을 화면 하나로 굴리는 도구.

**▶ [바로 써 보기](https://plusiam.github.io/play-team-demonstration/)**

---

## 무엇을 해결하나

칠판에 스코어보드를 그리면 이런 일이 생긴다.

- 사회자가 분필을 잡는 순간 시선이 학생에게서 떠난다
- 여러 칸을 도는 동안 몇 번째 칸인지 아이들도 교사도 헷갈린다
- 조건문을 즉석에서 떠올리느라 템포가 끊긴다

이 도구는 **조건문 제시 · 진행 위치 표시 · 점수 누적** 셋을 대신 들어준다.
사회자는 버튼만 누르면 된다.

---

## 학년 · 교과

- **대상** — 초등 3~6학년
- **교과** — 도덕, 창의적 체험활동, 학급 놀이. 교과를 가리지 않는다
- **교육과정** — 2022 개정 교육과정
- 기본 조건문에 **다문화 세트**가 들어 있다.
  답이 한국에서 나고 자란 아이에게 유리하지 않도록 짰다.
  이주배경 학생이 오히려 100점짜리를 아는 순간이 이 놀이의 목적지다

---

## 어떻게 노나

1. 모둠을 나누고 각 모둠에 **백지 한 장**을 준다
2. 화면에 조건문이 뜬다 — 예: `ㄱ으로 시작하는 동물`
3. 아이들이 백지에 답을 **여러 개** 적는다
4. 사회자가 답을 하나씩 부른다. 그 답을 적은 모둠이 손을 든다
5. 사회자가 화면에서 답을 고르고 손 든 모둠을 눌러 `반영`
6. 조건을 다 돌면 `결과`로 순위와 모둠별 획득 내역을 본다

**점수는 흔한 답일수록 낮다.** 30 / 50 / 100 세 단계.
아무도 생각 못 한 답을 적은 모둠이 이긴다.

### 보너스 콜

사회자가 **점수를 먼저 걸고** 답은 나중에 공개할 수 있다.
`★ 숨은 보너스 300점`이 화면에 뜨면 아이들이 술렁인다.
답을 모르니 **드문 답을 적는 쪽으로 움직인다.**

---

## 준비물

- 인터넷 되는 컴퓨터와 교실 TV(또는 빔프로젝터)
- 모둠별 백지 한 장, 필기구

학생 단말은 필요 없다. **손으로 쓰는 것이 이 놀이의 본질**이라 일부러 넣지 않았다.

---

## 쓸 때 알아두면 좋은 것

- **칸 수** — 4칸 10~14분 / **6칸 15~21분(기본)** / 8칸 20~28분.
  40분 한 차시라면 6칸이 설명·마무리까지 넣어 딱 맞는다
- **같은 답을 여러 모둠이 냈으면 전원이 그 점수를 다 받는다.** 나눠 갖지 않는다
- **감점은 없다.** 잘못 눌렀으면 `되돌리기`로 몇 번이든 거슬러 올라갈 수 있다
- **새로고침해도 점수가 살아 있다.** 브라우저에 자동 저장된다
- **다음 반 수업 전에는 `새 판`을 누르시라.** 안 그러면 앞 반 점수 위에서 시작한다
- 조건문은 직접 넣어도 된다.
  단, **답이 하나뿐인 조건문은 넣지 마시라.** 아는 아이만 웃는다

## 기술

- 단일 HTML 파일. 빌드 도구 없음, 프레임워크 없음
- **외부 요청 0건** — 인터넷이 끊겨도 돌아간다
- 학생 정보를 아무 데도 보내지 않는다. 모둠 이름과 점수만 브라우저 안에 남는다
- 반응형 — 교실 TV(1920px) 우선, 태블릿·휴대폰 대응

### 내려받아 쓰기

`index.html` 한 파일만 있으면 된다. 내려받아 더블클릭하면 열린다.

```bash
git clone https://github.com/plusiam/play-team-demonstration.git
```
